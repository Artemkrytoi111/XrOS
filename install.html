Установка XrOS

Важно: установка стирает данные на выбранном диске. Сделайте резервную копию важных файлов до начала.
  1. Скачайте ISO
    Когда релиз будет опубликован, ссылка появится на странице «Загрузка». Проверьте SHA-256 скачанного файла.
  2. Запишите ISO на USB
    Нужен накопитель от 8 ГБ. Подойдут balenaEtcher, Rufus или команда dd в Linux. Запись стирает всё содержимое USB.
  3. Загрузитесь с USB
    Включите компьютер, откройте меню загрузки (обычно F12, F8 или Esc) и выберите USB. Откроется live-система с KDE Plasma.
  4. Запустите установщик
    На рабочем столе live-системы — значок «XrOS Install». Установщик графический: bash-движок и Rust GUI.
  5. Разметка диска
    Выберите диск и схему разметки. При необходимости включите шифрование LUKS (опция, не обязательно).
  6. Пользователи и настройки
    Создайте пользователя, задайте пароль, выберите часовой пояс и раскладку клавиатуры.
  7. Установка и перезагрузка
    Дождитесь завершения установки, извлеките USB и перезагрузите компьютер. Система загрузится через GRUB (UEFI или BIOS).

LUKS — шифрование диска (опционально)

LUKS — необязательная опция установщика, а не обязательное требование. Если включить шифрование, при каждой загрузке нужно будет вводить пароль от диска. Без LUKS система загружается без дополнительного пароля.

После установки

При первом запуске откроется приветствие (PyQt6). Обновите систему:

sudo pacman -Syu

Подробнее о репозитории и пакетах — на странице «Пакеты», о подписях — на странице «Безопасность».

Примечания

  • Установщик работает только из live-системы — устанавливать «поверх» другой ОС нельзя.
  • Secure Boot не требуется и не настраивается установщиком.
  • Пароль GRUB не устанавливается — загрузчик работает без пароля.
