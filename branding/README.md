# XrOS — брендинг

> Логотип и обои прислала Мия 10 ноября 2026. Это реальный брендинг,
> утверждённый для XrOS 1.0. Исходники — `xros-logo-real.png`
> и `wallpaper-real.png`, они не перезаписываются.
> Производные делает `scripts/make-branding.py` — перегенерация
> воспроизводима, копии раскладываются по профилю и пакету.

Единый источник палитры — `branding/design-tokens.css`:

- **Фон:** `#08080D`
- **Доп. фон (панели, поля):** `#111018`
- **Акцент:** фиолетовый неон `#8B00FF`
- **Второй акцент (hover, ссылки):** `#B66AFF`
- **Текст:** `#F5F3FA`
- **Вторичный текст:** `#A6A0B3`
- **Границы:** `#30283B`
- **Тёмный акцент (нажатое состояние кнопок, см. `theme.rs`):** `#5A00B8`

- **Логотип:** чёрный металлический X с фиолетовым неоном, только
  символ X, без надписи внутри. Исходник `xros-logo-real.png`
  (1536×1024, RGBA) уже имеет настоящий альфа-канал: углы
  прозрачны (alpha = 0), ореолов и дыр нет — проверено 10.11.2026
  композитом на тёмной (`#08080D`), белой и шахматной подложке
  (`logo-check-dark.png`, `logo-check-light.png`,
  `logo-check-checker.png`). Поэтому маска по яркости не извлекается:
  она только обрезала бы неоновое свечение. Производный
  `xros-logo.png` — тот же файл, убрана только невидимая пыль
  (пиксели с alpha < 5 → 0, 13 760 px; байтовая копия исходника
  это НЕ — sha256 различаются). Гистограмма альфа: 68,1% полностью
  прозрачных, 30,9% непрозрачных (alpha 250–254), 0,9%
  полупрозрачных (антиалиасинг кромок и свечение).
  Маленький вариант для сайдбара установщика — `xros-logo-small.png`
  (400×274, RGBA, прозрачный фон): кроп по самому X
  (видимый bbox 52,6–1492,996 + отступ 24 px), делается ТОЛЬКО из
  прозрачного `xros-logo.png` (не из исходника напрямую).
  Квадратный кроп не подходит — X широкий, квадрат обрезал бы острия.
- **Обои:** чёрные, фиолетовые волны-ленты, по центру X, БЕЗ надписи
  «XrOS» (решение Мии 10.11.2026: основной вариант — без надписи,
  оставить символ X, волны и свечение, тёмный графитовый фон,
  минимализм). Исходник `wallpaper-real.png` (1672×941, RGB) —
  с надписью, он НЕ перезаписывается: это реальный файл от Мии.
  Надпись убирается при генерации (`scripts/make-branding.py`,
  `remove_text_wallpaper`): маска ярких пикселей в полосе надписи
  (y 574–646, x 590–1040; верх маски y=571 — ниже нижних остриёв
  X, которые заканчиваются около y=568–570) заполняется диффузией
  Лапласа от краёв маски. Первая попытка маски с y=540 задела
  острия X и свечение — исправлено сужением полосы. Проверено
  глазами 10.11.2026 (исходник рядом с очищенным, 2×, и полный
  кадр 1920×1080): X и его острия целы, следов надписи и границ
  маски не видно; тонкая волна-лента, проходившая за надписью,
  в зоне маски теряется (очень бледная, не читается). Производные
  `wallpaper.png` / `wallpaper.jpg` — 1920×1080: апскейл ×1,149
  (LANCZOS), кропа нет — соотношение исходника 1672:941 почти равно
  16:9, X целиком в кадре (проверено глазами 10.11.2026).
  JPG — качество 92.
- **Фон GRUB:** `grub-bg.png` / `grub-bg.jpg` 1024×768 (кроп 4:3
  по центру очищенных от надписи обоев). X попадает под зону меню
  (верх 30%, высота 45%), поэтому центр затемнён с растушёвкой:
  средняя яркость под меню — 5,8 (макс. 110), под таймером — 3,0,
  текст меню читается (проверено глазами 10.11.2026).
  Надписи «XrOS» на фоне GRUB нет.
- **Иконки GRUB:** `profile/grub/theme/*.png` — кружки с буквами
  (Xr, W, E, M, R, S) в фиолетовой палитре (`#8B00FF` / `#B66AFF`,
  9-слайс `select_*` — акцент `#8B00FF`, `terminal_box_*` —
  доп. фон `#111018` с границей `#30283B`). Рисованный набор иконок —
  следующим шагом, когда будет финальный набор. Отдельная иконка
  для SDDM не нужна: кастомной темы SDDM в проекте нет, используется
  стандартная тема Breeze с автовходом.

Копии реальных файлов: `profile/airootfs/usr/share/xros/`
(логотипы, обои, фон GRUB, `banner.txt`), `profile/grub/splash.*`,
`profile/grub/theme/grub-bg.*`,
пакет `xros-branding` (staged-копии в `packages/xros-branding/`,
см. `packages/xros-branding/PKGBUILD` — `prepare()` сверяет их
с `branding/`). Все копии — байтовые копии исходников из
`branding/`, их делает `scripts/make-branding.py` (и этап 2
`scripts/build.sh` для пакета).

- **Баннер:** `banner.txt` — одна строка `XrOS 1.0 — на базе
  Arch Linux.` (не ASCII-арт; печатается командой `xros` и
  используется как backtitle установщика). Канонический исходник —
  `branding/banner.txt`; копии — в `profile/airootfs/usr/share/xros/`
  и `packages/xros-branding/` (делает `scripts/make-branding.py`).
  Старых цветов и названий в баннере нет.
