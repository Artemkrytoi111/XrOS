- `SigLevel = Optional TrustAll` — подписи НЕ проверяются.

- `Server = https://xros.example/repo/$repo/os/$arch` (PLACEHOLDER:

  рабочая (снимок есть, см. 1.2).
- `profile/pacman.conf` == `profile/airootfs/etc/pacman.conf`
  (проверяется диагностикой, §9).
