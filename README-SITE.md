# XrOS — сайт проекта (GitHub Pages)

Готовый многостраничный сайт XrOS 1.0 Diamond: тёмный дизайн, адаптация для телефонов, русский язык. Никаких внешних CSS/JS/CDN — только локальные файлы.

## Деплой на GitHub Pages за 3 шага

1. **Создайте репозиторий** на GitHub (например, `XrOS` в аккаунте `Artemkrytoi111`) — или используйте существующий репозиторий сайта.
2. **Залейте файлы** из этого каталога в корень репозитория (ветка `main`).
3. **Включите Pages**: Settings → Pages → Source: «Deploy from a branch», Branch: `main`, Folder: `/ (root)` → Save. Сайт откроется по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Локальная проверка: откройте `index.html` в браузере или запустите `python3 -m http.server` в каталоге сайта.

```

```

## Как поменять base URL

Base URL сейчас — `https://artemkrytoi111.github.io/XrOS/` (репозиторий сайта XrOS). Если сайт будет жить в другом репозитории или на своём домене, замените этот адрес:

- в `sitemap.xml` — во всех `<loc>` и в `robots.txt` (строка `Sitemap:`);
- в `_config.yml` при необходимости добавьте `url: https://ваш-домен` и `baseurl: /имя-репозитория`.

Внутренние ссылки на страницах относительные, поэтому сайт работает и локально, и на любом адресе Pages без правок.

## Как поменять дату релиза

Когда релиз 1.0 Diamond будет опубликован:

1. В `download.html`: замените предупреждение «Релиз пока не опубликован» на кнопку/ссылку скачивания ISO и вставьте реальный SHA-256.
2. В `index.html` и `changelog.html`: обновите бейдж статуса и запись в истории.
3. В `faq.html`: обновите ответ «Где скачать ISO?».
4. В `sitemap.xml`: обновите `lastmod` у изменённых страниц.
