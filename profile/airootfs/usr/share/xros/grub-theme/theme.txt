# Обратный отсчёт (история fixed6/fixed9, 11.11.2026): @TIMEOUT@ GRUB
# 2.16 НЕ подставляет вообще, а @TIMEOUT_NOTIFICATION_*@ — только как
# ВСЁ значение text (точное grub_strcmp, не подстрока; доказано
# fixed7/fixed8 + исходником gui_progress_bar.c). Правильно: text —
# это printf-шаблон, draw_text() делает grub_xasprintf(template,
# |value|) — %d заменяется на секунды до автозагрузки.
# text = "Booting in %d seconds..." рендерится "Booting in 7 seconds...".
# id "__timeout__" обязан быть РОВНО ОДИН на весь theme.txt и именно
# на progress_bar (в label — никогда).
