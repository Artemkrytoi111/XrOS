# 11.11.2026 (fixed6): @TIMEOUT@ подставляется GRUB ТОЛЬКО в progress_bar
# с id "__timeout__" (в label — никогда; доказано установленной системой:
# fixed5-label показывал литерал "@TIMEOUT@"). Поэтому обратный отсчёт —
# это progress_bar: число в тексте + заполнение фиолетовым. Label с
# @TIMEOUT@ удалён; единственный компонент с id "__timeout__" — этот bar.
# 11.11.2026 (fixed8): ОШИБКА fixed6: @TIMEOUT@ GRUB НЕ подставляет
# вообще — в fixed7 меню показало литерал "@TIMEOUT@". Доказательство:
# strings gfxmenu.mod (GRUB 2.16) содержит только __timeout__ и
# @TIMEOUT_NOTIFICATION_LONG@ / _MIDDLE@ / _SHORT@ (замены:
# LONG — "The highlighted entry will be executed automatically in %ds.",
# MIDDLE — "%ds remaining.", SHORT — "%ds").
# 11.11.2026 (fixed9): ОШИБКА fixed8: SHORT тоже показался литералом.
# Точный механизм — исходник GRUB gui_progress_bar.c,
# progress_bar_set_property(): плейсхолдеры сравниваются через
# grub_strcmp СО ВСЕМ значением text (точное совпадение), а не как
# подстрока. Поэтому "Автозагрузка через @TIMEOUT_NOTIFICATION_SHORT@"
# не подставляется. Правильно: text — это printf-шаблон, draw_text()
# делает grub_xasprintf(template, |value|) — %d заменяется на секунды
# до автозагрузки. text = "Автозагрузка через %d с" рендерится
# "Автозагрузка через 7 с".
