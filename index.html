XrOS 1.0 Diamond

Дистрибутив Linux на базе Arch Linux. Live-система с KDE Plasma, графический установщик, подписи GPG и автообновления — без лишнего шума.

Возможности

💿

Графический установщик

Установщик с bash-движком и Rust GUI: разметка диска, пользователи, LUKS как опция — без терминала.

🖥️

KDE Plasma

Современный рабочий стол Plasma в live-системе: загрузился с USB — и сразу работаешь.

🔐

Безопасность по умолчанию

SigLevel = Required: все пакеты и база репозитория подписаны GPG. Неподписанный пакет просто не установится.

🔄

Автообновления

Репозиторий обновлений XrOS с подписанными пакетами — система обновляется штатным pacman.

🩺

Диагностика

Проверки системы и установщика: сотни автоматических тестов, включая проверку ISO 12/12 PASS.

🎨

Тема Sapphire

Фирменная тема GRUB Sapphire и брендинг Diamond: чёрный металл и фиолетовый неон.

Как устроена система

XrOS — это Arch Linux с готовой live-средой. В основе — ядро Arch и репозитории, сверху — собственные пакеты XrOS: установщик, приветствие, брендинг, CLI-утилита и связка ключей. Загрузка — только GRUB, поддерживаются UEFI и BIOS.

КомпонентЧто это
БазаArch Linux, x86_64
Рабочий столKDE Plasma (live-система)
Установщикbash-движок + Rust GUI
ПриветствиеPyQt6, команда xros
ЗагрузчикGRUB, тема Sapphire, UEFI + BIOS
ОбновленияСобственный репозиторий, SigLevel = Required
