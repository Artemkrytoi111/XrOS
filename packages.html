Пакеты XrOS

Собственные пакеты системы. Все пакеты и база репозитория подписаны GPG, установка — только с проверкой подписи (SigLevel = Required).

ПакетВерсияНазначение
xros-installer1.0-6Графический установщик системы (bash-движок + Rust GUI)
xros-welcome1.0-3Приветствие системы после установки (PyQt6)
xros-branding1.0-2Фирменное оформление Diamond: тема GRUB Sapphire, логотипы
xros-cli1.0-2Утилита командной строки xros
xros-keyring1.0-1Ключи подписи репозитория (переходный пакет ротации ключа)

Обновление системы

sudo pacman -Syu

Установка связки ключей

sudo pacman -S xros-keyring

Настройка репозитория [xros]

Добавьте в конец файла /etc/pacman.conf:

[xros]
SigLevel = Required
Server = https://artemkrytoi111.github.io/XrOS-Security-Updates/xros/os/$arch

После этого обновите базы и систему: sudo pacman -Syu. Подробнее о подписях — на странице «Безопасность».
