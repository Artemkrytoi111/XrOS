# xros-cli — команда `xros` (Rust).
# Сборка: cargo build --release; бинарь ставится в /usr/local/bin/xros
# (пакет xros-cli). Зависимостей, кроме libc, нет.
#
# Команды:
#   xros            — информация о системе
#   xros info       — то же самое
#   xros update     — pacman -Sy (нужен root)
#   xros upgrade    — pacman -Su (нужен root)
#   xros --help     — справка
#   xros --version  — версия
