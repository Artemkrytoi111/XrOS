# XrOS 1.0 Diamond — премиальный графический установщик

## Что это
Новый графический установщик XrOS 1.0 Diamond. Заменяет Rust-egui GUI
(`src/xros-install-gui-rs`, пакет xros-installer 1.0-3) как основной
установщик. Движок НЕ переписан: используется существующий bash-движок
`src/xros-install` (75 КБ) через тот же контракт, что и старый GUI.

## Контракт с движком (не менять)
- GUI пишет `/tmp/xros-install.conf` (режим 0600, `ключ=значение` с
  shell-экранированием), затем запускает `/usr/local/bin/xros-install`
  с `XROS_NONINTERACTIVE=1` и `XROS_INSTALL_CONF=/tmp/xros-install.conf`.
- Лог движка: `/tmp/xros-install.log` (читается построчно, показывается
  на экране установки как есть).
- Ключи конфига: `PARTMODE` (erase|manual), `FS` (ext4|btrfs|xfs),
  `TIMEZONE`, `KEYMAP`, `AUTOLOGIN` (0|1), `OFFICE`, `DE` (kde),
  `FULLNAME`, `USERNAME`, `USERPASS`, `ROOTPASS`, `DISK`, `ROOT_PART`,
  `HOSTNAME` (по умолчанию xros-os).
- Движок сам валидирует значения и защищает диск с ISO.

## Стек
- Хост: Python + PyQt6 (`QQmlApplicationEngine`), уже есть в Live-системе
  (`python-pyqt6`). QML: `qt6-declarative` + `qt6-quickcontrols2` —
  добавляются в `profile/packages.x86_64` (в Live rootfs их пока нет).
- Запуск из окна приветствия: `src/xros-welcome` вызывает
  `/usr/local/bin/xros-installer-diamond` (через sudo, как раньше
  вызывался xros-install-gui). Старый Rust GUI остаётся как запасной.
- Закрытие установщика НЕ завершает Live-сессию: приложение просто
  выходит, окно приветствия остаётся.

## Структура
- `main.py` — точка входа: QApplication, загрузка QML, мост в контекст.
- `bridge.py` — `InstallerBridge` (QObject): реальные диски через lsblk,
  часовые пояса, раскладки, запись конфига, запуск/отмена движка,
  чтение лога, перезагрузка.
- `qml/Theme.qml` — утверждённая палитра XrOS.
- `qml/Main.qml` — оболочка: боковая панель, StackView, нижняя панель.
- `qml/screens/*.qml` — 8 экранов (см. ТЗ Diamond).
- `qml/components/*.qml` — общие элементы (кнопки, карточки, поля).
- `qml/strings.js` — строки интерфейса (русский / English).

## Правила (из ТЗ Diamond)
- Название «XrOS 1.0 Diamond» — везде, никогда просто «XrOS 1.0».
- Палитра только утверждённая: фон #08080D, доп. фон #111018,
  акцент #8B00FF, второй акцент #B66AFF, текст #F5F3FA,
  вторичный текст #A6A0B3, границы #30283B.
- НИКАКОГО общего прогресса: ни полосы, ни процента, ни индикатора
  в боковой панели и нижней панели. На экране установки — только
  индикатор текущей операции + реальный статус и лог.
- Разметка диска: только реальные диски (lsblk), подтверждение
  перед форматированием с точным именем диска и списком изменённых
  разделов, никогда без подтверждения, никогда авто-выбор физ. диска.
- Все элементы управления выполняют реальные действия; никаких
  статичных/фальшивых данных.
- Адаптивность: 1280×720, 1366×768, 1600×900, 1920×1080.
